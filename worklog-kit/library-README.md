# 내 자료 (자료)

이 폴더의 `목록.md` 에는 내가 Claude 에게 건넨 링크와 파일이 한 줄씩 쌓입니다.
Claude 는 세션을 시작할 때 최근 자료를 먼저 보고, 관련 작업을 할 때 이 목록부터 찾아봅니다.
지난주에 건넨 자료를 다시 찾아 붙여 넣지 않아도 되게 만드는 폴더입니다.

## 어떻게 쌓이나

| 시점 | 무엇이 일어나나 |
|---|---|
| 내가 링크나 파일 경로를 건넬 때 | 목록에 없는 것만 날짜와 함께 한 줄 적힙니다. Claude 가 잊어도 빠지지 않습니다 |
| Claude 가 그 자료를 열어 봤을 때 | 그 줄의 '무엇'(어떤 자료인지)과 '언제'(어떤 작업에 다시 쓰나) 칸을 채웁니다 |
| 세션을 시작할 때 | 최근 15줄이 Claude 에게 먼저 보입니다 |

긴 글을 통째로 붙여 넣으면 그 안의 링크까지 줍지 않도록 앞뒤 일부만 봅니다. 한 번에 5개까지 적습니다.

## 목록의 모양

```
- 2026-10-28 · https://docs.google.com/spreadsheets/d/… · 무엇: 10월 매출 시트(재무팀) · 언제: 월 마감 보고를 쓸 때
- 2026-10-28 · ~/Downloads/업체A_카탈로그.pdf · 무엇: ? · 언제: ?
```

`?` 는 Claude 가 아직 그 자료를 열어 보지 않았다는 뜻입니다. 열어 보지 않은 자료의 설명은 지어내지 않습니다.

## 지켜지는 것

- 링크 뒤에 token, key, sig 같은 비밀값이 붙어 있으면 그 부분을 잘라 내고 적습니다
- 비밀번호나 개인 연락처가 담긴 자료면 Claude 가 그 줄을 지우고 알려 줍니다
- 필요 없는 줄은 직접 지워도 됩니다
