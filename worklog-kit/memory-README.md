# 내 규칙 (memory)

이 폴더에는 내가 Claude 에게 '다음부터 이렇게 해 줘'라고 고쳐 준 것이 규칙 파일로 쌓입니다.
Claude 는 세션을 시작할 때마다 `MEMORY.md`(규칙 목록)를 먼저 읽고, 관련 작업을 할 때 그 규칙 파일을 열어 따릅니다.
같은 말을 두 번 하지 않게 만드는 폴더입니다.

## 어떻게 쌓이나

| 시점 | 무엇이 일어나나 |
|---|---|
| 내가 고쳐 달라고 말할 때 | '다음부터', '하지 마', '그게 아니라', '기억해' 같은 말이 보이면 Claude 에게 저장 여부를 판단하라는 안내가 붙습니다 |
| Claude 가 저장할 때 | 이번 한 번만의 지시는 저장하지 않고, 다음에도 지킬 규칙만 `feedback_주제.md` 한 파일로 씁니다. 답 끝에 '규칙으로 저장: memory/…' 라고 알려 줍니다 |
| 세션을 시작할 때 | `MEMORY.md` 목록이 Claude 에게 먼저 보입니다 |

꼭 남기고 싶으면 '기억해'라고 말하면 됩니다. 반대로 저장된 규칙이 틀렸으면 그 파일을 지우거나 '그 규칙 지워 줘'라고 말하면 됩니다.

## 규칙 파일의 모양

```
---
name: 표는 3열까지
type: feedback
date: 2026-10-28
---
규칙: 표는 3열을 넘기지 않는다. 넘으면 표를 둘로 나눈다
이유: 휴대폰으로 보면 4열부터 잘린다(내가 10/28에 말함)
언제: 슬랙·메일에 붙일 표를 만들 때
```

`MEMORY.md` 에는 한 줄만 붙습니다.

```
- [표는 3열까지](feedback_표는-3열까지.md) — 언제: 슬랙·메일에 붙일 표를 만들 때
```

## 작성 기준 (Claude 가 이 수준으로 씁니다)

| 항목 | 반드시 들어갈 것 |
|---|---|
| **규칙** | 무엇을 하고 무엇을 하지 않나. 한 파일에 규칙 하나 |
| **이유** | 내가 말한 이유 그대로. 말하지 않았으면 지어내지 않고 '이유 미확인' |
| **언제** | 어떤 작업을 할 때 이 규칙을 꺼내 보나. 목록에서 이 줄만 보고 열지 말지 정할 수 있게 |

같은 주제의 규칙이 이미 있으면 새 파일을 만들지 않고 그 파일을 고칩니다. 목록이 30줄을 넘으면 겹치는 규칙을 합칠 때입니다.

## 설정

- **끄기:** 이 프로젝트의 `.claude/settings.json` 에서 `feedback_capture.py` · `feedback_session.py` 가 들어간 줄을 지웁니다(업무일지는 그대로 돕니다)
- **업무일지와의 관계:** 규칙 파일을 쓰는 것도 파일 수정이라 업무일지에 한 줄 기록됩니다
